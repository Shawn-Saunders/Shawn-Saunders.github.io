# Intro to Web Development Coursework

## Overview

A collection of lab work for Intro to Web Development based on MDN challenges

## Coursework

| Lab | Topics |
|---|---|
| Lab 1 | Semantic HTML, document structure, forms |
| Lab 2 | HTML structure, tables, data representation |
| Lab 3 | CSS, typography, layout |
| Lab 4 | JavaScript, DOM manipulation, forms |
| Lab 5 | Web accessibility, WCAG principles, accessible controls |

## Accessibility

The final lab focused on applying web accessibility principles including semantic HTML, keyboard accessibility, focus management, accessible multimedia, ARIA, contrast, and WCAG-oriented testing.
