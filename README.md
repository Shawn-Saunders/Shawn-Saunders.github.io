# Intro to Web Development Coursework

## Overview

A collection of lab work for Intro to Web Development based on MDN challenges

## Challenges

- Lab 1: Marking up a letter & Structuring a page of content 
- Lab 2: Creepy crawly splash page & Structuring planet data
- Lab 3: Styling a biography page, Typesetting a homepage, & Fundamental layout comprehension
- Lab 4: Silly story generator, Image gallery, Object building (bouncing balls), & Structuring a feedback form
- Lab 5: Web accessibility
- index.html: Basic index used as a baseline for all projects
